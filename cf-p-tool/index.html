cfnew 节点管理助手

VLESS / Trojan · 反代与出站管理
原理说明
客户端连接入口优选IP（节点 @ 后地址）→ CF 边缘 → Worker ── 优先直连目标；直连失败才走 p（ProxyIP 反代）或 s（SOCKS5/HTTP 代理）。 工具内部把节点解析为对象再改参数、重建 URI（p/s/wk/rm 写入 path 随连接生效，优先级高于面板/环境变量）。仅支持 VLESS / Trojan（WS、XHTTP）。

2节点管理与编辑

4ProxyIP 测试辅助

每条节点 × 每行 ProxyIP 全组合输出 —— 铺开测速找最快反代

参数详解（源码依据：cfnew「明文源吗」第 3323–3331 行 WS 处理函数、第 4185 行 解析代理配置）

p：出站 ProxyIP，直连失败时改走。支持 ip、ip:端口、[IPv6]:端口、域名，可逗号分隔多个。

s：出站代理，接受 socks5:///socks:///http:///https:// 前缀或裸 user:pass@host:port（无前缀按 SOCKS5）。

wk（节点层）：Worker 地区，影响分区回退；订阅层为筛选优选地区。rm（节点层）：仅 rm=no 有效；订阅层为移除地区。

XHTTP 节点的连接参数 Worker 不读取，出口请用「3 订阅参数生成」管理。
