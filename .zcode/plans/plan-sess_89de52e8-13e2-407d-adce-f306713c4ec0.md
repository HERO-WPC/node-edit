# 目标

你已找到一批反代 IP（ProxyIP），想要一个工具把 `p` 这类参数批量加到节点上，方便切换/测试不同出站反代。

# 步骤

## 1. Clone 项目到本地（用你的代理）
```
git clone --depth 1 https://github.com/byJoey/cfnew.git "D:\桌面\节点-edit\cfnew"
```
clone 时通过 `http://127.0.0.1:10808` 代理（git config 或环境变量方式）。

## 2. 本地源码确认 p 参数的确切机制（决定工具怎么做）
在源码里重点查证：
- WS 连接（VLESS/Trojan 首包处理）出站时，ProxyIP 除了环境变量/KV 外，**是否解析节点请求 path/query 里的 `p`/`proxyip`**（例如 `/?ed=2048&p=1.2.3.4`），确切格式和支持的参数名是什么；
- xhttp 出站是否同样支持 path 传 p；
- 订阅 URL `?p=xxx` 影响的是节点生成还是出站连接。

结论只有两种可能，工具方案对应：
- **节点 path 支持内嵌 p** → 工具为每个反代 IP 生成一份节点副本（path 带各自的 p），输出合并订阅，实现"每条节点各自走不同反代"；
- **仅订阅 URL 支持 p** → 工具为每个反代 IP 生成一条订阅 URL 清单（`/{uuid}/sub?p=该IP`），逐个导入测试。

## 3. 做工具（单文件本地 HTML，双击即用，无需安装环境）
放在 `D:\桌面\节点-edit\` 下，功能：
- 粘贴框 1：节点链接（支持 vless:// trojan://，多行/整段订阅 base64 均可，自动拆分）；
- 粘贴框 2：反代 IP 列表（每行一个，支持 `ip`、`ip:端口`、`域名`）；
- 按步骤 2 确认的格式批量生成：每条节点 × 每个 IP 的输出（path 内嵌 p 或订阅 URL 清单）；
- 输出可一键复制 / 下载为 .txt，生成 base64 订阅文本可直接导入客户端。

## 4. 验证
用你贴过的那三条真实节点（vless+xhttp / vless+ws / trojan+ws）+ 几个反代 IP 跑一遍，检查生成结果的参数编码（URL 转义、path 格式）无误。
